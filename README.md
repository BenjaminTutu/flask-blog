# Flask Blog Application

A simple blog application built with Flask.  
The app supports **admin-managed posts** and **user comments**.

---

## Features

  Admin
- Add new blog posts
- Delete existing blog posts

   Users
- View blog posts
- Comment on posts
- User details (such as name/email) appear beneath each post along with their comment

---

## Technologies Used

- Python
- Flask
- HTML (Jinja templates)
- CSS
- SQLite (or your chosen database)

---

Usage

Admin users can create and delete blog posts.
Regular users can comment on posts.
Each comment displays the commenter’s details beneath the post.
